# 更新日志

## [1.0.0] - 2026-07-15

### 新增（首次发布）

- **完整AI病毒识别库**：6大病毒类型检测（逻辑连接词过载、情绪直接标注、说明文句式、形容词堆砌、节奏机械化、对话过于规整）
- **6种风格定制方案**：简洁冷峻、文艺细腻、口语化接地气、古典雅致、快节奏爽文、悬疑紧张
- **四阶段工作流程**：需求收集 → AI病毒扫描 → 方案提交 → 执行改写
- **质量评分系统**：5维度改前改后对比评分
- **性别平等与角色尊重准则**：禁止物化、刻板印象、功能化角色
- **持续学习机制**：记录作者反馈，持续优化

### 核心原则

- 不做任何假设
- 先问后动
- 绝不使用固定模板
- 详细解释每一步
