# 网文去AI化手术刀 v 1.0

专为网络小说作者定制的AI写作痕迹清除系统

> 去除AI机械感，保留作者灵魂。尊重每一种风格，服务每一位创作者。

---

## 这是什么？

一个专门为网络小说作者设计的AI写作辅助工具。它像一位专业的外科医生，精准识别并清除文本中的AI写作痕迹，同时完整保留你的个人风格。

### 核心功能

| 功能 | 说明 |
|------|------|
| 🔍 AI病毒扫描 | 6大AI特征检测（连接词过载、情绪标注、说明文句式等） |
| ✂️ 精准清除 | 只去除AI机械感，不动你的风格 |
| 🎨 风格定制 | 6种风格方案：简洁冷峻/文艺细腻/口语化/古典/快节奏/悬疑 |
| 📊 质量评分 | 改前改后多维度对比，量化提升效果 |
| 📝 逐句分析 | 每处改动都解释原因，帮你学习成长 |

## 快速开始

### 只需要3步

第1步：复制Skill指令

1. 点击本仓库中的 `SKILL.md` 文件
2. 点击右上角的 「Raw」 按钮
3. 全选（Ctrl+A）并复制所有内容

第2步：粘贴到AI工具

打开以下任一AI工具，将复制的内容粘贴发送：

- Claude（推荐）
- ChatGPT (GPT-4o)
- Kimi
- DeepSeek

第3步：按AI提示操作

AI会引导你完成：

1. 提交需要改写的文本
2. 回答风格需求问题
3. 确认诊断报告和改写方案
4. 获取改写结果和评分

## 能处理什么问题？

### 6大AI病毒识别

| 病毒类型 | 特征 | 示例 |
|----------|------|------|
| 逻辑连接词过载 | 此外、而且、不仅...而且 | "他打开门。此外，他还检查了窗户。" |
| 情绪直接标注 | 感到、觉得、意识到 | "她感到非常紧张。" |
| 说明文句式 | 这体现了、这说明 | "这标志着人生的转折。" |
| 形容词堆砌 | 精致的、优雅的、美丽的 | "她拥有美丽的秀发和精致的五官。" |
| 节奏机械化 | 句长统一、段落刻板 | 每句都是15-20字 |
| 对话过于规整 | 完整句、缺语气 | "你好，请问你对这件事怎么看？" |

## 风格定制方案

| 风格 | 适用类型 | 操作特点 |
|------|----------|----------|
| 简洁冷峻 | 悬疑、硬汉、末世 | 删除80%形容词，多用短句 |
| 文艺细腻 | 言情、成长、治愈 | 保留感官描写，五感并用 |
| 口语化接地气 | 都市、喜剧、日常 | 加语气词，允许口语语法 |
| 古典雅致 | 古言、仙侠、历史 | 文言句式，注意音韵 |
| 快节奏爽文 | 升级流、打脸、热血 | 密集爆点，短句紧迫 |
| 悬疑紧张 | 推理、惊悚、悬疑 | 碎片信息，压迫感环境 |

---

## 设计原则

1. 不做任何假设 — 不预设主角性别、读者性别、小说类型
2. 先问后动 — 先诊断，再方案，确认后执行
3. 绝不使用固定模板 — 每次改写都是新的创作
4. 详细解释每一步 — 让作者理解并学习
